Stage 1 · Explanation

What this project does

01

Validate

Check rows, columns, missing values, duplicates, data types, and the class balance before modeling.

02

Model

Use a stratified 80/20 split and compare a majority baseline, Logistic Regression, Decision Tree, and Gradient Boosting.

03

Evaluate

Look beyond accuracy: recall, precision, F1, specificity, ROC-AUC, PR-AUC, and the confusion matrix explain the trade-offs.

Analysis outline

  1. Upload and validate dataIdentify the binary target and confirm the dataset is usable.
  2. Explore outcomes and predictorsVisualize the class distribution and numeric feature patterns.
  3. Train comparable modelsTune Gradient Boosting without using the final test set.
  4. Interpret carefullyFeature importance is predictive association, not causation or medical advice.
Experiment defaults: 80% train / 20% test · stratified split · random seed 42 · event class = 1 · threshold = 0.50
