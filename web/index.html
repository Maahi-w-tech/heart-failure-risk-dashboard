03 · Make sense of it

The whole algorithm in four ideas

Gradient descent is a repeated feedback loop. It does not “know” medicine; it only finds weights that reduce prediction error on the examples it was shown.

01x

Start with inputs

Each patient is represented by numbers such as age, ejection fraction, and serum creatinine.

x = [age, EF, creatinine, …]
02w

Combine with weights

The model multiplies every standardized input by a learned weight and adds them together.

z = b + Σ(wᵢ × xᵢ)
03σ

Turn it into probability

The sigmoid squashes the weighted sum into a value between 0 and 1.

p = 1 / (1 + e−z)
04↺

Learn from error

The gradient points toward more loss. Subtracting it updates the weights in a better direction.
